# Release Process

Public releases correspond to meaningful M3HT4 capability milestones.

## Suggested release naming

```text
v1.0.0 — Infrastructure Foundation
v2.0.0 — Enterprise Networking
v3.0.0 — Detection Engineering
```

## Release checklist

- [ ] Documentation updated
- [ ] Architecture diagrams updated
- [ ] Public content sanitized
- [ ] Workflows passing
- [ ] Screenshots reviewed
- [ ] Changelog updated
- [ ] Tag and release notes created
