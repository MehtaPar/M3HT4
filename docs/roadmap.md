# M3HT4 Roadmap

M3HT4 follows an incremental delivery strategy: build a small useful artifact, validate it, document it, then expand.

## Phase 1 — Public foundation

**Goal:** establish a clear, safe, and maintainable project baseline.

- finalize Modern Hunting Terrain branding;
- define the 3 Teams and 4 Pillars;
- align the public repository;
- document public/private boundaries;
- remove broken navigation and outdated positioning.

## Phase 2 — First validated scenario

**Goal:** demonstrate the complete M3HT4 workflow.

- define one authorized scenario objective;
- map behavior to expected evidence;
- generate representative telemetry in a controlled environment;
- document the hunt workflow;
- validate detection opportunities;
- publish a sanitized after-action review.

## Phase 3 — Reusable framework artifacts

**Goal:** standardize what worked.

- scenario brief template;
- evidence map;
- hunt plan;
- emulation plan;
- detection-validation record;
- after-action review.

## Phase 4 — Curated scenario library

**Goal:** expand carefully without becoming a data dump.

- add scenarios only after validation;
- tag content by team, pillar, evidence source, and objective;
- document limitations and prerequisites;
- retire or revise stale content.

## Phase 5 — Interactive platform

**Goal:** turn proven workflows into a guided web experience.

- searchable scenarios and artifacts;
- team-specific perspectives;
- guided engagement planning;
- interactive evidence and workflow views;
- lightweight hosting and maintenance.

## Delivery principle

The interactive application should **follow validated content**, not precede it.
