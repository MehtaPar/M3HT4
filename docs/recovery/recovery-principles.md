# Recovery Principles

1. A backup is not proven until it is restored.
2. Snapshots are not replacements for independent backups.
3. Persistent identifiers are safer than changing device names.
4. Critical storage should be separate from the hypervisor boot disk.
5. Recovery documentation should be tested, not merely written.
6. Major changes require a rollback point.
7. Validation must include application services—not just VM power state.
