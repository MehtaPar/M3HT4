# Sanitized Examples

Examples in this directory must be safe for public use and useful without access to private infrastructure.

## Required characteristics

- use fictional or reserved-example identifiers;
- explain the learning or validation objective;
- identify expected evidence at a high level;
- include authorization and safety assumptions;
- document limitations;
- avoid real credentials, endpoints, or private data.

## Approved placeholder patterns

```text
host.example.lab
192.0.2.10
AA:BB:CC:XX:XX:XX
<REDACTED_UUID>
<REDACTED_TOKEN>
```

Never copy live operational files directly into this directory.
